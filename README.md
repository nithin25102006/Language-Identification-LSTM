# Language Identification Using LSTM

## Project Overview
This project identifies the language of text using a deep learning LSTM model.

## Technologies
- Python
- TensorFlow
- LSTM
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
The dataset contains text samples from 22 languages.

## Model Performance
- Accuracy: 90.68%
- Precision: 90.23%
- Recall: 90.68%
- F1-Score: 89.69%

These are the results obtained during testing. Performance on unseen text may vary.

## Installation

Install dependencies:

pip install -r requirements.txt

## Run the Project

python main.py
